# Boot UI fonts

The USOS boot menu (UEFI, Legacy BIOS and the micro-Linux framebuffer UI)
draws text from `src/gui/fonts/usos-font.bin`, a compact 4-bit anti-aliased
glyph pack generated by `python tools/usos_font_gen.py` from these sources:

| File | Font | License |
|------|------|---------|
| `Roboto-Regular.ttf`, `Roboto-Medium.ttf` | Roboto 2.137 (Google) | Apache License 2.0, `LICENSE-Apache-2.0.txt` |
| `NotoSans-UsosSymbols.ttf` | Subset of Go Noto Current Regular 2.012 (Noto Sans glyphs: arrows U+2190-2193, check mark U+2713) | SIL Open Font License 1.1, `LICENSE-OFL-1.1.txt` |

Roboto is Copyright 2011 Google Inc., licensed under the Apache License,
Version 2.0. The generated pack is a derived rendering of these fonts and is
distributed under the same terms; this directory, including both license
texts, travels with the source tree.

## What the pack contains

- Only the codepoints the boot UI can show: printable ASCII, UI punctuation
  and arrows, and every character used by any `boot.*` string or language
  name in `installer/internal/i18n/locales` (Latin-1 and Latin Extended-A
  diacritics, Romanian comma-below letters, Greek, Cyrillic).
- Four roles (small 13 px, body 15 px, strong 15 px medium, heading 21 px
  medium), each in two natively hinted tiers: 1x and 1.5x. The renderer
  draws 2x and 3x by bilinear upscaling of a tier (1440p and 4K).
- `go run ./cmd/usos-i18n-gen -root ..` (in `installer/`) fails when any
  language needs a glyph the pack lacks; rerun the font generator after
  adding strings with new characters.
