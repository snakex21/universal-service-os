## Open items

- **Standard-mode browser GPF.** Still open. The Codex Trumpet A/B run in
  QEMU did not reproduce it (see `winsock-standard-regression.md`). 386
  enhanced mode stays the default for the Winsock profile.
- **PDB reuse caveat.** Win16 Winsock contexts are now keyed by HTASK + PDB.
  If DOS reuses a PDB segment for a new task with the same HTASK, a stale
  context could still match. Check the diagnostic log (`USOS_WS_DIAG=1`
  trail) the next time the Micron disk is read.
- **Mouse wheel in 386 enhanced mode.** Design A from
  `win3x-wheel-enhanced-2026-10-25.md` is not implemented yet.
- **"File creation error" during the 3.0a install.** Still shows up after the
  redirect guards (every redirection target directory is made first). The
  install completes. Parked as a known cosmetic issue for the Win3 polish
  round. Next step: a trace with echo on to find which line prints it.
- **Windows 1.x/2.x DOS-shell mouse.** Not tested on X470 in this round.
- **Legacy Core at the 4096 B limit.** No room for more code in the Legacy
  Core without first making space.
