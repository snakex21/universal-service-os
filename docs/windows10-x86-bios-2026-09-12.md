# Windows 10 22H2 x86 — BIOS, 12 września 2026

Windows 10 ma teraz natywny start ISO w BIOS przez `Automatic` i `ISO`.
Core otwiera obraz z `Systems/Windows/Windows 10/Images`, odczytuje jego
oryginalne pliki startowe i przekazuje je do wimboot. W Windows PE helper
odnajduje tę samą partycję DATA po GUID i sprawdza rozmiar wybranego ISO.
DATA oraz obraz są mapowane tylko do odczytu, a następnie uruchamiany jest
`sources/setup.exe` z tego obrazu. Opcjonalny plik odpowiedzi pochodzi z
katalogu `Windows 10/Unattended`.

Ścieżka korzysta z istniejących helperów x86/x64. Nie przygotowuje kopii
instalatora w WORK ani nie uruchamia mikro-Linuksa. Wybór katalogu źródłowego
został wydzielony do małego profilu; testy zachowują dotychczasową ścieżkę
Visty. Routing Windows 7, NT5 oraz UEFI pozostał zgodny z wcześniejszymi testami.

- Rozmiar: 4 467 318 784 bajty.
- SHA-256: `d45968dae085e7a28e6531b528b28810e2d8423d581b2629edb1e29367823d7a`.
- UDF, `sources/install.wim`; oba obrazy w `boot.wim` mają architekturę x86.
- Zainstalowana edycja: Windows 10 Pro 32-bit, kompilacja 19045.6396.

Suma identyfikuje plik użyty w teście i jego kopie. Nie przeprowadzano
porównania z opublikowaną przez Microsoft sumą oryginalnego wydania.

- Odczyt GPT → NTFS → UDF porównano z niezależnym odczytem przez 7-Zip.
  Rozmiary i SHA-256 wszystkich sześciu plików są zgodne, w tym całego
  `install.wim` o rozmiarze 3 782 183 163 bajtów.
- Pełna instalacja w VirtualBox BIOS: menu USOS → wybrany ISO → Windows PE
  → Windows 10 Pro → pusty dysk 32 GiB → restart → odłączenie źródła USOS
  → dalsza instalacja z samego dysku → konfiguracja konta → pulpit.
- Gość miał 2 GiB RAM, dwa procesory logiczne i profil Athlona 64 X2 4200+.

  32-bitową oraz 2 147 012 608 bajtów dostępnej pamięci fizycznej.

`31c644bf-74dd-4807-9cb2-46745adeadd4` otrzymał wydanie

Kopię najpierw zapisano pod nazwą tymczasową, sprawdzono SHA-256 i dopiero

Standardowy silnik aktualizacji zakończył wszystkie pięć etapów wynikiem

Po testach VM została poprawnie wyłączona. Usunięto dwie pośrednie kopie
obrazu nośnika; zachowane materiały testowe zajmują około 13,3 GB, a wraz
z oryginalnym ISO około 17,8 GB. Zainstalowany dysk testowy nie był montowany
w systemie gospodarza.

## Próba na sprzęcie i granice

Użytkownik potwierdził działanie na fizycznym Socket 939 / MS-7100.
Potwierdzenie dotyczy sprawdzonej instalacji i konfiguracji sprzętowej;
nie oznacza osobnej walidacji wszystkich sterowników i funkcji urządzeń.

Na Kingstonie wybór prowadzi przez Windows → Windows 10 → wskazany ISO →
Automatic → None. Dysk docelowy wybiera się w oryginalnym instalatorze
Windows. Po pierwszym restarcie instalatora należy uruchomić dysk docelowy,
np. przez wyjęcie pendrive'a; nie rozpoczynać instalacji ponownie.

Ta walidacja dotyczy wskazanego ISO x86 i BIOS. Nie potwierdza startu Windows
10 x64 na tym procesorze ani UEFI IA32. Obecny czytnik wymaga UDF i
`install.wim`; ESD, podzielone WIM oraz kompresja/szyfrowanie/sparse NTFS
nie są objęte tą ścieżką. Nazwy wybieranych plików muszą być ASCII.
