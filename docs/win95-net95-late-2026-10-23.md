# Windows 95 build 950: preserve TCP/IP after GUI Setup

The original GUI network detection replaces the static TCP/IP and client
classes installed before the first GUI boot. In closed RTM hives, R111
found all expected NET95 entries before GUI Setup and seventeen missing
entries afterwards. NWLink and NetBEUI had replaced the TCP/IP class.
Reapplying NET95 to the installed system restored actual DHCP in R114,
but Winsock registration was also missing. The companion TCP95 change
supplies those original network settings (dependency 7b1bb3b0, equivalent
to the separate Winsock commit 8a67c111).

For source version `4 0 0 950` with static NET95 only, REG95.BAT now calls
NET/NET95L.BAT before its existing early-import completion check. The new
helper requires the first import and network-file preparation to have
completed. It exports the original RunOnce key with the target's own DOS
REGEDIT. While the RunOnce\Setup subtree exists it leaves both registry
hives and its completion markers unchanged. After that subtree is gone,
it imports only NET95.REG and TCP95.REG, verifies fresh exports, restores
the registry file attributes and records NLATE.OK. It does not reapply
display, identity or other early answer settings.

An interrupted or failed late import leaves NLATE.RUN or NLATE.ERR and
the parent withholds Windows startup. Old verification exports are
deleted and their deletion checked before the import, so a failed export
cannot be accepted through a stale file. NLATE.OK prevents further late
imports. Other source versions and configurations retain their previous
behavior. There is no timer, automatic retry, desktop helper or forced
restart.

Host validation: five new tests cover scope, the Setup boundary, journal
failure handling, permitted imports and the original DOS line/label
limits. Nineteen relevant existing tests passed before the final removal
of stale exports; the five boundary tests passed again after it.

Runtime validation is pending. R117 is prepared to execute this exact
helper on a pre-GUI overlay and check that both entire hives remain
unchanged. R118 is prepared to apply it to the installed R110 base.
R119 checks that overlay read-only, and R120 will test only network
behavior in the installed guest. These are new disposable overlays;
none starts Windows Setup. The superseded globals-only R115 case will
not run. Previously passed USB and Standard VGA restart checks are not
repeated. Full normal-install and physical X470 behavior remain unproved.

No full release build, merge, push, deployment, hub or NT4 USB change.
