# Windows 95 RTM/OSR1: FAT16 preparation — runtime test pending

Branch `fix/win95-usb`, base `6476cd9515813af4ef8f58657d398189181947d1`.
This removes an installation prerequisite blocking tests of these older
95 editions. It does not change the USB, network or hub drivers.

The existing 9x path always made FAT32. The new own policy reads the root
SETUP.EXE version resource without executing it. Original 95 launcher
version 4.0.0.950 selects FAT16, partition type 06h, 32 KiB clusters and
a maximum 2047 MiB C: partition. Real start/end CHS agree with LBA under
the existing 255-head/63-sector geometry. Space beyond C: remains unused
apart from the existing CSMWrap ESP. This avoids the FAT16 cluster-count
boundary at a full 2 GiB partition.

Known OSR2 launchers keep FAT32. The FAT32 MBR entry and existing 98/98SE/Me
selection are unchanged. Unknown/missing 95 identity stops before any
target write. A modified/mixed/custom 95 source is not certified by this
launcher check. The change does not establish RTM USB/NDIS compatibility.

The existing PE version reader now supports bounded NE RT_VERSION entries,
checking the ANSI VS_VERSION_INFO key, fixed-info signature, lengths,
alignment, resource ID and conflicting versions. It never scans arbitrary
code for a version signature. PE32/PE32+ behavior is retained.

Read-only checks against the five local originals:

| Source | Root launcher version | Selected filesystem |
|---|---|---|
| Windows 95 RTM PL OEM | 4.0.0.950 | FAT16 |
| Windows 95 OSR1 EN OEM | 4.0.0.950 | FAT16 |
| Windows 95 OSR2 EN OEM | 4.0.0.1068 | FAT32 |
| Windows 95 OSR2.5 EN OEM | 4.0.0.1068 | FAT32 |
| Windows 95 OSR2.1 PL control | 4.0.0.1111 | FAT32 |

Source and launcher SHA-256 are in `artifacts/setup-versions.json`; original
ISOs and temporary Windows files stayed in the approved collection.
The Win95 subfolder's DOS bootstrap SETUP.EXE does not carry that version;
the check deliberately uses the original root launcher.

Host verification: 10 tests PASS for real shell policy/MBR bytes, CHS/LBA,
FAT16 bound, unchanged FAT32 entry, original PE formats and malformed,
conflicting or out-of-resource NE version data. C build with warnings as
errors and shell syntax checks PASS. No physical disk writes, no release
build, no merge. Fresh RTM/OSR1 boot and actual mkfs/system behavior in QEMU
are still required, including a suitable legitimate boot floppy and key.
