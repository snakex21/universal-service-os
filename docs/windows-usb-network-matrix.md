## Ograniczenia i kolejność

- NT4 Workstation PL + SP6a: świeży normalny przepływ OVMF → USOS → micro-Linux → CSMWrap; zewnętrzny QEMU `igb` (8086:10C9). Candidate03 ukończył Setup/pulpit, osobny HID01 PASS [S14]; osobny installed LAN07 ma zakończony strict dowód [S16]; MSC i nowy IRQ89/08 nadal wymagają własnych testów, bez przenoszenia wyników NT351.
- W2K/XP/NT5.2: osobno weryfikować faktycznie zainstalowany kontroler, USBSTOR i NIC; stare SP mają blokady pakietu. R11/R12 używają prawidłowego celu 32 GiB thin qcow2.
- Vista SP2 / 2008 SP2 x86: wymagany własny świeży test, wspólny skrypt i importy nie wystarczają. R13 ma osobny prywatny cache fix/nt6x86-usb i donor x86.
- NT3.51: [S7] potwierdza świeży Workstation R22 i LAN; [S4] osobny diagnostyczny USB/HID. Bez MSC. Dawne około2s opóźnienie zachowano jako historię; installed candidate [S8] je usuwa i przechodzi osobną regresję HID R27. Inne nośniki i Server wymagają osobnych testów.
- QEMU IRQ nie odtwarza braku IRQ karty I211 na X470; działanie pollingu 20 ms pozostaje bramką sprzętową.
- Poprawka `fix/nt6x86-usb` (`4f54df6b`, `655af5ef`): błąd instalacji notyfikatora zatrzymuje restart; log przy EXE, bez PUBLIC fallback. Host PASS, runtime oczekuje. Nie scalono ani nie wdrożono.
