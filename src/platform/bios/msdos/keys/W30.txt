# waits for its dialog on the screen (pix: plane-0 hash of a black-and-white

# script allowed, its keys went into the copy and the dialogs waited for a
# person. Answers: no printers, no application search, no documents
# (Continue); "make all modifications" (Continue); OK to the saved
# CONFIG.SYS/AUTOEXEC.BAT note; "Return to DOS" in the exit dialog (its
# focused button restarts Windows, Reboot one restart too many: USOS

# 60 bytes x 12 lines); the note's first text line (24, 196, 34 x 14).
