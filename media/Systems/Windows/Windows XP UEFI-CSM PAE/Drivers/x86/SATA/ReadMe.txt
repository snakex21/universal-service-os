Manual Installation ->

The files "storport.sys" and "ntoskrn8.sys" must be copied FROM the folder ".\Patches\Miscellaneous" INTO
the folder "C:\WINDOWS\system32\drivers". And after that the Microsoft SATA/AHCI driver can be installed.
